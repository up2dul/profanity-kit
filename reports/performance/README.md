# Performance evidence

`phase-4.json` is generated by `scripts/benchmark-performance.mjs` from the
packed npm artifact. It uses the generated English and Indonesian corpora and
measures initialization, short/long no-match and match paths, repeated matches,
and one- versus multiple-language detectors.

Each case records the median of five samples of 10,000 iterations. Its budget is
three times the first validated baseline, which catches material regressions
while allowing ordinary hosted-runner variance. Run `pnpm performance:benchmark`
to refresh the baseline and `pnpm performance:check` to enforce it.

The report intentionally does not publish a competitor ranking: a comparison is
only meaningful with equivalent, licensed corpora and identical semantics. The
neutral fixtures and methodology are recorded so a later competitor study can
be added without changing the package benchmark contract.
