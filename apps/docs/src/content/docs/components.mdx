## Factories

- `createDetector()` from `profanity-kit` creates an English detector.
- `createDetector({ languages })` from `profanity-kit/core` creates a detector
  from one or more explicit language packs.

## Detector methods

- `check(input)` returns as soon as it finds a match.
- `isClean(input)` is the readable inverse of `check()`.
- `findAll(input)` returns ordered `ProfanityMatch` records.
- `filter(input, options?)` replaces matches while preserving source text.

## Language packs

`profanity-kit/languages/en` and `profanity-kit/languages/id` export readonly
`LanguagePack` values. A custom pack supplies `code`, `name`, `version`, and a
readonly `words` array.

See the [configuration guide](/configuration) for allowlists, block lists, and
replacement behavior.
